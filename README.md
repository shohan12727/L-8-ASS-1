
## Assignment Overview 

This assignment cover eight different problem and with two blog writting which is cover the basic and intermediate level typescript concept.

Topic cover: Functions and default Parameters, Union Types and Type Narrowing, Tuples and Readonly,Generics, Interfaces and Filtering, Generics, Inheritance ,Asynchronous Programming

## Blog Posts

1. **[TypeScript Compilation and the Role of tsconfig.json](./ts-completion-config.md)**

   Explains how TypeScript code is compiled into JavaScript using the `tsc` compiler and how `tsconfig.json` manages compiler options, type checking, and project configuration.

2. **[Understanding Generics in TypeScript and Asynchronous Promise Responses](./generic-work-with-async-promise.md)**

   Explores how Generics improve code reusability and type safety, particularly when working with asynchronous functions and `Promise<T>` responses.
